## How to view locally

Just open `index.html` in a browser.

## Deploy to GitHub Pages

1. Create a new repository (e.g. `portfolio` or `yourusername.github.io`).
2. Upload these files to the root of the repo:
   - `index.html`
   - `styles.css`
   - `README.md`
3. In the repo settings → Pages → Source: select the branch (`main`) and folder `/ (root)`.
4. Your site will be live at `https://yourusername.github.io/portfolio` (or similar).

## Notes

- No JavaScript required.
- No build step needed — plain HTML and CSS only.
