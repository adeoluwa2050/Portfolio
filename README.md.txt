## How to view locally

Just open `index.html` in a browser, or run a simple local server:

```bash
# Python
python -m http.server 8000

# or Node
npx serve .
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a new repository (e.g. `portfolio` or `yourusername.github.io`).
2. Upload these files to the root of the repo (or to a `/docs` folder).
3. In the repo settings → Pages → Source: select the branch and folder.
4. Your site will be live at `https://yourusername.github.io` (or `https://yourusername.github.io/repo-name`).

## Customisation

- Update contact details in `index.html` if needed.
- Colours and fonts are in `styles.css`.
- No build step required — plain HTML, CSS, and a tiny bit of JavaScript.
